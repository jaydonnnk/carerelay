One plan, passed hand to hand

The plan is a yellow appointment slip. It is the only bright object on every screen. Colour says who is acting, so a judge can see where Tencent ADP works and where code decides without reading a ledger.

Colour rules

  • The plan. Folded away while Mei says it back, so her answer is recall, not copying.
  • Tencent ADP reading words. Used for nothing else.
  • CareRelay code deciding, and the patient's single next action.
  • Nobody has agreed to help yet.
  • Anything simulated. Hatched, so it cannot pass for real.

Screens

  • Judge startReplaces “Try an example”. Who Mei is, the four steps, and where ADP is and is not used.
  • Patient: your next stepApproved copy, icons restored, one primary button. Consent controls move to their own step.
  • Patient: say it backPlan slip folded face down. “Show my plan” unfolds it and is recorded as a hint.
  • Judge view: the checkLive call 20: Mei says 8pm, ADP copies three phrases, code catches the time.
  • Judge view: request failedThe simulated booking fails. The deadline stays, the case stays open, Mei still acts.

Type

Atkinson Hyperlegible Next, drawn by the Braille Institute for low-vision readers. One family for everything; its mono cut only for the raw ADP reply.

Judge-facing evidence — not the patient’s screen

Two independent axes

Evidencenone

Closure state: open — one named party must still act. The deadline has not moved.

clinical_deadline = 2026-09-21T18:00 (unchanged) policy_version = v1 (unchanged) attempt[0].route = clinic-sim-01 attempt[0].status = failed (no availability) evidence = none next_owner = patient closure = open

The two axes never collapse into one ladder. “Booked” would be execution acknowledged with evidence none — which is not care.

What must hold under fault
  • I1 Immutable deadline. The retry did not move 6:00 PM. Only a versioned, clinician-backed reassessment can.
  • I2 No false completion. A failed request is never rendered as resolved.
  • I3 Idempotency. A duplicate callback or a restart does not advance state.
  • I4 Named owner. Exactly one party must act, or the screen says plainly that nobody does.
  • I5 Missing is not negative. No reply is not a “no.”

Sharing with a caregiver requires permission. A caregiver message is not proof that care happened.

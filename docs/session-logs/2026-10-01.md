1. **`service.py:510`** `_score`'s `understood` drops the uncertainty half in a
   mutant and the whole suite stays green. An unrecognised restatement then records
   `recall_unaided` instead of `not_recalled`, contradicting its own
   `understood: false`. Fix: assert the outcome in
   `test_an_unresolvable_span_is_uncertain_and_never_a_mismatch`.
2. **`models.py:73`** `HintLevel.H1 -> RECALL_SCAFFOLDED` has no test anywhere.
   Contract line "H0 to H3 recorded" is 3/4 evidenced; the cited test exercises H2
   only. Fix: parametrise over all four levels.
3. **`service.py:263`** intake binding is a bare substring match. A red-flag
   complaint containing the bound phrase is scored, and a negated one is scored.
   Test name and status record both overstate the rule. Fix is a decision, not a
   tweak; no red-flag detection may be authored without a reviewer.

## Reusable lesson

A mutation that changes an outcome *mapping* (rather than a guard) can survive a
suite that only ever asserts the guard's refusal. The guard tests here were
excellent and the outcome-mapping tests were thin. When reviewing a slice whose
contract is a table of recorded values, mutate the mapping table itself, not only
the branches that refuse.
